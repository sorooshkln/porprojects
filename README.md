# لندینگ ناردون

پیاده‌سازی راست‌به‌چپ بر اساس تصویر مرجع با HTML، CSS و JavaScript، بدون وابستگی خارجی در زمان اجرا. فونت‌های ابر برای تیترها و دانا برای متن‌ها از فایل‌های ارائه‌شده توسط کارفرما به‌صورت محلی بارگذاری می‌شوند. تمام وزن‌های ارسال‌شده در `assets/fonts/` قرار دارند؛ تیترها از وزن‌های SemiBold و Bold ابر و متن‌ها از Regular و Medium دانا استفاده می‌کنند.

## اجرا

```sh
cd /workspace/porprojects
npm start
```

سرور روی پورت 3000 اجرا می‌شود. برای اجرای سرور، Node.js نسخهٔ ۱۸ یا جدیدتر کافی است و نصب پکیج لازم نیست. تغییر فایل‌های HTML، CSS، JavaScript و تصاویر، صفحهٔ باز مرورگر را خودکار بازخوانی می‌کند. پایش فایل‌ها با بررسی دوره‌ای انجام می‌شود و به قابلیت recursive watch سیستم‌عامل وابسته نیست. Python 3 فقط برای ساخت خروجی HTML مستقل لازم است.

آدرس `http://localhost:3000` روی همان دستگاهی باز می‌شود که سرور را اجرا کرده است. دسترسی از بیرون محیط نیازمند پیش‌نمایش یا اتصال پورت است.

## ساختار

- `index.html`: ساختار صفحه، بنرها، آیکن‌ها و پنجره‌ها
- `style.css`: ظاهر، فاصله‌گذاری و نمایش واکنش‌گرا
- `app.js`: داده‌های نمونه، فیلتر، جستجو و سبد خرید محلی
- `assets/`: فونت‌های محلی

تصاویر سه پارت فیگما در `assets/design-top/`، `assets/design-part2/` و `assets/design-part3/` قرار دارند. تصاویر مقالات از مجموعه تصاویر طراحی انتخاب و برای کارت‌های مقالات برش داده شده‌اند و در `assets/articles/` هستند. عرض نهایی محتوا طبق درخواست ۱۲۳۰ پیکسل است. چیدمان زیر ۷۶۸ پیکسل مطابق مرجع جدید موبایل، شامل جابه‌جایی بنر قسطی، بودجه، محصولات، فروشگاه‌های چهارستونه و منوی ثابت پایین است.

آیکن‌ها SVGهای رسمی Phosphor هستند و داخل صفحه جاسازی شده‌اند؛ مجوز آن‌ها در `assets/icons/PHOSPHOR-LICENSE.txt` قرار دارد. برای نمایش صفحه نیازی به CDN نیست.

اسلایدر هیرو سه اسلاید با محوشدن تدریجی، پخش خودکار هر شش ثانیه، دکمه توقف، انتخاب نقطه، کلیدهای جهت و سوایپ دارد. پخش هنگام خروج از دید، تغییر تب، تمرکز کیبورد و قرار گرفتن ماوس متوقف می‌شود. اسلایدرهای محصولات، نظرات، فروشگاه‌ها، تصاویر دایره‌ای و مقالات با اسکرول واقعی و کنترل‌های راست‌به‌چپ کار می‌کنند. حالت کاهش حرکت سیستم‌عامل رعایت می‌شود.

محصولات، قیمت‌ها و متن‌های ناخوانای تصویر، دادهٔ نمونه هستند. فرم ورود نمایشی است و ارسال پیامک انجام نمی‌دهد؛ سبد خرید در حافظه صفحه نگهداری می‌شود. مقالات به‌صورت محلی در پنجره مطالعه باز می‌شوند؛ پرداخت به سرویس واقعی متصل نیست. برای تطبیق پیکسلی، فایل اصلی فیگما و دارایی‌های نهایی لازم است.

نمایش در عرض‌های ۳۲۰، ۳۶۰، ۳۹۰، ۴۱۴، ۷۶۸، ۱۰۲۴، ۱۴۴۰ و ۱۹۲۰ پیکسل، چیدمان موبایل، اسلایدرها، مقاله‌ها و تعامل‌های اصلی با Chromium بررسی شده‌اند.

برای بازسازی نسخهٔ تک‌فایلی دارای فونت‌ها و تصاویر داخلی، `python3 scripts/build-preview.py` را اجرا کنید. خروجی `preview.html` است.
