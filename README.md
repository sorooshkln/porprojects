# لندینگ ناردون

پیاده‌سازی راست‌به‌چپ بر اساس تصویر مرجع با HTML، CSS و JavaScript، بدون وابستگی خارجی در زمان اجرا. فونت‌های ابر برای تیترها و دانا برای متن‌ها از فایل‌های ارائه‌شده توسط کارفرما به‌صورت محلی بارگذاری می‌شوند. تمام وزن‌های ارسال‌شده در `assets/fonts/` قرار دارند؛ تیترها از وزن‌های SemiBold و Bold ابر و متن‌ها از Regular و Medium دانا استفاده می‌کنند.

## اجرا

```sh
cd /workspace/porprojects
npm start
```

سرور روی پورت 3000 اجرا می‌شود. برای اجرای سرور، Node.js نسخهٔ ۱۸ یا جدیدتر کافی است و نصب پکیج لازم نیست. تغییر فایل‌های HTML، CSS، JavaScript و تصاویر، صفحهٔ باز مرورگر را خودکار بازخوانی می‌کند. پایش فایل‌ها با بررسی دوره‌ای انجام می‌شود و به قابلیت recursive watch سیستم‌عامل وابسته نیست. Python 3 فقط برای ساخت خروجی HTML مستقل لازم است.

آدرس `http://localhost:3000` روی همان دستگاهی باز می‌شود که سرور را اجرا کرده است. دسترسی از بیرون محیط نیازمند پیش‌نمایش یا اتصال پورت است.

## ساختار

- `index.html`: ساختار صفحه، بنرها، آیکن‌ها و پنجره‌ها
- `style.css`: ظاهر، فاصله‌گذاری و نمایش واکنش‌گرا
- `app.js`: داده‌های نمونه، فیلتر، جستجو و سبد خرید محلی
- `assets/`: فونت‌های محلی

تصاویر و اندازه‌های بخش بالایی، از هدر تا دو بنر پس از جدیدترین محصولات، از فایل فیگمای ارسالی استخراج و اعمال شده‌اند. پارت دوم نیز شامل ۱۰ تصویر دایره‌ای، ۶ لوگوی فروشگاه، تصاویر پرفروش‌ترین‌ها و هدیه و بنر شمش سرمایه‌گذاری در `assets/design-part2/` اعمال شده است. پارت سوم نیز تصاویر شمش‌ها، محصولات پیشنهادی، آواتارهای برداری نظرات و دو بنر طلا و الماس را پوشش می‌دهد. تصاویر جدید در `assets/design-part3/` قرار دارند. تصاویر بخش مطالب آموزشی و نمادهای پایین صفحه تا دریافت فایل مربوط به آن‌ها خاکستری باقی مانده‌اند. فایل مرجع عرض ۱۲۸۰ پیکسل، محتوای ۱۱۲۰ پیکسل و حاشیه‌های ۸۰ پیکسل دارد؛ نوار مرورگر ۷۴ پیکسلی تصویر، جزو سایت پیاده‌سازی نشده است. تصاویر و پروانهٔ برداری این بخش در `assets/design-top/` قرار دارند. برای افزودن تصاویر نهایی، پس‌زمینه جایگاه‌های `.placeholder` را با تصاویر متناظر جایگزین کنید. بنرها از `.hero`، `.small-banner` و `.wide-banner` استفاده می‌کنند؛ تصاویر محصولات از `.product-image`.

محصولات، قیمت‌ها و متن‌های ناخوانای تصویر، دادهٔ نمونه هستند. فرم ورود نمایشی است و ارسال پیامک انجام نمی‌دهد؛ سبد خرید در حافظه صفحه نگهداری می‌شود. مقاله‌ها و پرداخت به سرویس واقعی متصل نیستند. برای تطبیق پیکسلی، فایل اصلی فیگما و دارایی‌های نهایی لازم است.

نمایش و نبود سرریز افقی در عرض‌های 375، 413، 768، 1024 و 1440 پیکسل و تعامل‌های جستجو، فیلتر، سبد خرید، منوی دسته‌بندی و اسلایدر با Chromium بررسی شده‌اند.

برای بازسازی نسخهٔ تک‌فایلی دارای فونت‌ها و تصاویر داخلی، `python3 scripts/build-preview.py` را اجرا کنید. خروجی `preview.html` است.
