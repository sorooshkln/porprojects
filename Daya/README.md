# Daya

پروژهٔ مستقل از ناردون، با HTML، CSS و JavaScript و بدون وابستگی npm.
پیاده‌سازی صفحهٔ فروشگاهی بر اساس فایل `Daya Sample (3).fig` و دارایی‌های داخل همان فایل.

## اجرای محلی

Linux و Node.js 18.19.1 یا جدیدتر کافی است. نصب پکیج لازم نیست.
در پوشهٔ Daya اجرا کنید:

```sh
npm run dev
```

آدرس: http://localhost:3002 — با تغییر HTML، CSS، JavaScript و فایل‌های assets مرورگر خودکار بازخوانی می‌شود.
سرور از بررسی دوره‌ای فایل‌ها استفاده می‌کند و به recursive fs.watch وابسته نیست؛ با Linux و Node 18 سازگار است.
اگر پورت اشغال باشد، سرور با خطا متوقف می‌شود و پورت دیگری انتخاب نمی‌کند.
توقف: Ctrl+C. اجرای npm start هم همین سرور را اجرا می‌کند.

## دریافت در پوشه‌ای جدا روی سیستم شما

ریپو: https://github.com/sorooshkln/porprojects
مسیر فعلی ناردون: /home/soroosh/Documents/Nardoon-live — پورت 3000.
مسیر پیشنهادی Daya: /home/soroosh/Documents/Daya — پورت 3002.
دستورهای زیر برای راه‌اندازی اولیه‌اند و پوشهٔ مقصد باید از قبل وجود نداشته باشد:

```sh
git clone --filter=blob:none --sparse https://github.com/sorooshkln/porprojects.git /home/soroosh/Documents/Daya
git -C /home/soroosh/Documents/Daya sparse-checkout set Daya
cd /home/soroosh/Documents/Daya/Daya
npm run dev
```

پوشهٔ بیرونی checkout ریپو است و پوشهٔ داخلی کد برنامه. این روش checkout ناردون را تغییر نمی‌دهد.
برای دریافت تغییرات بعدی، در همین checkout دستور git pull --ff-only را اجرا کنید.
ناردون و Daya را در دو ترمینال جدا اجرا کنید.

## فایل‌ها

- index.html: ساختار صفحه
- style.css: ظاهر
- app.js: تعامل‌ها
- assets/fonts/: فونت‌های ارسالی
- assets/data/: داده‌های ارسالی
- scripts/live-server.mjs: سرور مستقل Daya

تمام تغییرات این پروژه باید در Daya/ بمانند. فایل‌های ریشهٔ ریپو متعلق به ناردون هستند.

## تطبیق با فیگما

فریم مرجع `Brand Landing` عرض ۱۵۱۲ و ارتفاع ۵۷۳۶ پیکسل دارد. محتوای طراحی‌شده تا ارتفاع ۲۱۱۹ ادامه دارد؛ بقیهٔ فریم خالی است. نوار مرورگر ۵۳ پیکسلی بالای ماکاپ بخشی از رابط سایت نیست و در HTML تکرار نشده است. فضای خالی انتهای بوم هم به صفحه اضافه نشده است.

در عرض ۱۵۱۲، عرض محتوا ۱۳۱۲، فاصلهٔ طرفین ۱۰۰، ارتفاع هدر سایت ۲۲۰، بنر ۵۵۰ و فاصلهٔ بین بخش‌ها ۱۰۰ پیکسل است. چیدمان چهارستونهٔ دسته‌ها و محصولات، تایپوگرافی، قیمت‌ها و متن محصولات از فایل استخراج شده‌اند. در فایل، نام هر چهار محصول یکسان است؛ همین متن حفظ شده و برای تصاویر، توضیح جایگزین مستقل وجود دارد. رابط در عرض‌های کوچک به دو ستون برای دسته‌ها و فهرست قابل اسکرول محصولات تبدیل می‌شود؛ در فایل ارسالی فریم موبایل وجود ندارد.

تصاویر اصلی، لوگوی دایا و مدل‌های بنر از فایل ارسالی استخراج و به WebP تبدیل شده‌اند. برش تصاویر دسته‌ها بر اساس تبدیل‌های خود فیگماست. لوگوی کوچک Superdry و ستارهٔ هدر از مسیرهای برداری خود فیگما استخراج شده‌اند. نگاشت فایل‌ها به شناسهٔ لایه و هش تصویر اصلی در `assets/data/figma-assets.json` قرار دارد. فونت‌ها و تصاویر داخل Daya هستند و صفحه هیچ وابستگی‌ای به فایل‌های ناردون یا CDN ندارد.

فونت‌ها: ابر Low FaNum SemiBold، دانا FaNum Regular و Medium (کپی مستقل از فایل‌های موجود ریپو) و Abhaya Libre SemiBold برای عنوان انگلیسی (نسخهٔ آزاد Google Fonts؛ مجوز OFL کنار فونت است). فونت‌های سایر کامپوننت‌های داخلی و نوار مرورگر فیگما در این صفحه استفاده نشده‌اند.

## تعامل‌ها و محدوده

جستجو، فیلتر دسته و زنانه/مردانه/بچگانه، بازنشانی فیلترها، جابه‌جایی محصولات، جزئیات محصول و انتخاب سایز کار می‌کنند. فیلتر دسته‌های بدون محصول، نتیجهٔ خالی نشان می‌دهد؛ دادهٔ ساختگی به مجموعهٔ ارسالی اضافه نشده است. ترتیب محصولات در نمایش چهارستونه با کنترل‌های جابه‌جایی تغییر می‌کند و در عرض کوچک با اسکرول نیز قابل پیمایش است.

سبد خرید محلی است و برای تطبیق با شمارندهٔ فیگما، بار اول دو کالای نمونه دارد. تعداد، مبلغ کل و حذف کالا کار می‌کند؛ موجودی هر محصول حداکثر ۱۰ عدد است. وضعیت در localStorage همین مرورگر نگهداری می‌شود. اطلاعات ورود، تماس و مقاله در فایل ارسالی موجود نیست؛ کنترل‌های مربوط پنجرهٔ توضیحی باز می‌کنند. ورود، ثبت سفارش، پرداخت و ارسال پیام به سرور متصل نیستند. سه نقطهٔ بنر بخشی از ظاهر مرجع هستند؛ فقط همان یک اسلاید ارائه‌شده نمایش داده می‌شود.

## بررسی

کد و سرور با Node.js 18.19.1 بررسی شده‌اند: مسیرهای HTTP و فایل‌های محلی، بازخوانی خودکار، فیلترها و جستجو، نتیجهٔ خالی، انتخاب سایز، افزودن/حذف سبد، جمع مبالغ و ذخیرهٔ محلی. بررسی تعاملی DOM با ابزار موقت خارج از پروژه انجام شده و وابستگی‌ای به پروژه اضافه نمی‌کند. در محیط این اجرا ابزار کنترل مرورگر در دسترس نبود؛ تطبیق نهایی تصویری در مرورگر تأیید نشده است.
