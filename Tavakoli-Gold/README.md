# Tavakoli-Gold | طلای توکلی

پیاده‌سازی مستقلِ طرح ارائه‌شده در `TavakoliGold.fig`؛ این پوشه هیچ‌کدام از فایل‌ها، تنظیمات یا پورت پروژهٔ ناردون را تغییر نمی‌دهد.

## اجرا روی Linux با Node.js 18.19.1

اگر ریپو را از قبل در پوشه‌ای مستقل از ناردون گرفته‌اید، وارد پوشهٔ `Tavakoli-Gold` همان نسخه شوید. برای دریافت یک نسخهٔ جدا در کنار ناردون:

```bash
cd /home/soroosh/Documents
git clone https://github.com/sorooshkln/porprojects.git Tavakoli-Gold-repo
cd Tavakoli-Gold-repo/Tavakoli-Gold
npm run dev
```

آدرس: **http://127.0.0.1:3001**

نصب پکیج لازم نیست. Node.js 18.19.1 کافی است. اگر nvm دارید، `nvm use` نسخهٔ ثبت‌شده در `.nvmrc` را انتخاب می‌کند.

ناردون در `/home/soroosh/Documents/Nardoon-live` و روی پورت `3000` باقی می‌ماند. دستورهای بالا را در پوشهٔ ناردون اجرا نکنید. پوشهٔ `Tavakoli-Gold-repo` نسخهٔ جداگانهٔ ریپو است و پوشهٔ برنامهٔ جدید داخل آن قرار دارد.

`npm start` نیز همان سرور را اجرا می‌کند. تغییر HTML، CSS، JavaScript، فونت و تصویر باعث بازخوانی خودکار صفحه می‌شود. پایش با polling و SSE انجام می‌شود و به `fs.watch` بازگشتی وابسته نیست؛ با Linux و Node.js 18 سازگار است. اگر پورت مشغول باشد، سرور خطا می‌دهد و پورت ناردون یا پورت دیگری را خودکار انتخاب نمی‌کند.

برای پورت دیگر، مثلاً `PORT=3002 npm run dev`. سرور به‌صورت پیش‌فرض فقط روی loopback گوش می‌دهد. برای دسترسی شبکهٔ محلی، در صورت نیاز `HOST=0.0.0.0 npm run dev` را اجرا کنید و از IP دستگاه و پورت 3001 استفاده کنید.

## انطباق با طراحی

- دو چیدمان مستقل از فریم‌های اصلی استخراج شده‌اند: دسکتاپ `1512 × 4542` و موبایل `390 × 2224` پیکسل.
- در عرض کمتر از 900 پیکسل، چیدمان موبایل و در عرض‌های بالاتر، چیدمان دسکتاپ نمایش داده می‌شود. مقیاس در هر حالت نسبت ابعاد فریم را حفظ می‌کند. عرض دسکتاپ حداکثر 1512 و موبایل حداکثر 600 پیکسل است؛ صفحه در نمایشگر بزرگ‌تر وسط قرار می‌گیرد.
- نوار تکرار نام برند، پس‌زمینهٔ بخش پرفروش‌ها و جداکنندهٔ پلکانی مستقل از عرض محتوای مرکزی تا دو لبهٔ پنجره گسترش می‌یابند. نام نوار «توکلی» است و با فونت محلی دوران نمایش داده می‌شود. دو پترن تزئینی کنار بخش سفارش اختصاصی حذف شده‌اند.
- 25 تصویر اصلی، مسیرهای برداری، برش تصاویر، فاصله‌ها، رنگ‌ها و شکل‌های پلکانی از فایل استخراج شده‌اند. تصاویر و شش وزن فونت دوران محلی هستند و صفحه به CDN متکی نیست.
- فیگما علاوه بر دوران شامل فونت‌هایی مانند Peyda و فونت سیستم آیفون است. برای حفظ دقیق شکل و جای حروف، نوشته‌های ثابت به‌صورت مسیرهای اصلی SVG با متن معادل برای دسترسی‌پذیری نگهداری شده‌اند. رابط‌های تعاملی و متن‌های پویا از فونت‌های دوران ارسالی استفاده می‌کنند. صفحه یک تصویر تخت نیست؛ هر گروه، شکل و کنترل عنصر جداگانه دارد.
- نوار وضعیت آیفون و نوار پایین مطابق فریم موبایل حفظ شده‌اند؛ نوار پایین مطابق رفتار ثبت‌شده در فیگما به پایین پنجرهٔ مرورگر ثابت می‌شود. فضای انتهای صفحه اجازه می‌دهد محتوا زیر نوار پنهان نماند.

## تعامل‌ها و محدودهٔ داده

منوی موبایل، پیمایش بخش‌ها، جستجوی محلی، بازشدن کارت محصول، افزودن و حذف از سبد، ذخیرهٔ سبد در مرورگر و پیش‌نویس سفارش اختصاصی فعال‌اند. ردیف‌های محصول و دسته‌های طولانی موبایل با کشیدن افقی و کلیدهای جهت روی کنترل‌های آن ردیف جابه‌جا می‌شوند.

نام و قیمت‌ها عین اطلاعات طرح هستند. طرح اطلاعات مستقلی برای نتایج هر دسته، متن کامل مقاله‌ها، API قیمت لحظه‌ای، احراز هویت یا پرداخت ارائه نکرده است؛ این بخش‌ها به سرویس واقعی متصل نشده‌اند. ذخیرهٔ پیش‌نویس سفارش فقط در مرورگر است و چیزی به فروشگاه ارسال نمی‌کند. سبد در شروع خالی است و نشان تعداد با وضعیت واقعی سبد هماهنگ می‌شود.

## فایل‌ها

- `index.html`: پوستهٔ فارسی و راست‌به‌چپ، پنجره و نقاط ورود صفحه.
- `design.js`: دادهٔ چیدمان، متن‌ها و مسیرهای اصلی استخراج‌شده از فیگما؛ شامل `layouts.desktop`، `layouts.mobile` و `paths`.
- `renderer.js`: ساخت عناصر مستقل DOM و رسم SVG، تصاویر و حروف.
- `app.js`: کنترل‌ها، جستجو، سبد محلی، فرم پیش‌نویس و حرکت ردیف‌های موبایل.
- `style.css`: شش وزن دوران، مقیاس‌بندی و ظاهر رابط‌های تعاملی.
- `assets/`: تصاویر اصلی و فونت‌ها.
- `scripts/live-server.mjs`: سرور و بازخوانی خودکار مستقل روی پورت 3001.

ویرایش متن ثابت در `design.js` به‌تنهایی خطوط اصلی حروف را عوض نمی‌کند. برای نمایش متن ویرایش‌شده با فونت دوران، آرایهٔ `glyphs` همان نوشته را خالی کنید؛ رندرکننده متن `text` را با فونت محلی نمایش می‌دهد. برای تطبیق دقیق نوشتهٔ تازه با طرح باید مسیرهای آن از نسخهٔ جدید فیگما استخراج شوند.

## بررسی

```bash
npm run check
npm test
```

آزمون رندر، معتبر بودن دستور آغازین تمام مسیرهای SVG و ارجاع حروف در هر دو چیدمان را بررسی می‌کند؛ نشانگر بستن مسیر در ابتدای خطوط حروف فیگما پیش از درج در SVG حذف می‌شود.

آزمون سرور با همان نسخهٔ Node اجرا می‌شود و یک پورت آزاد موقت می‌گیرد؛ پورت 3000 را اشغال نمی‌کند. دریافت صفحه، MIME فونت و تصویر، جلوگیری از سرو فایل‌های خارج از محدوده، متدهای مجاز و رسیدن رویداد بازخوانی پس از ایجاد فایل جدید را بررسی می‌کند و فایل موقت را پاک می‌کند.

بررسی نحو و آزمون سرور با Node.js **18.19.1** انجام شده‌اند. رندر DOM و تعامل‌های اصلی در محیط DOM بدون مرورگر در 13 عرض از 320 تا 1920 پیکسل بررسی شده‌اند. دسترسی به پیش‌نمایش مرورگر در محیط اجرا فراهم نبود؛ تطبیق پیکسلی در مرورگر و آزمون لمس روی دستگاه واقعی هنوز تأیید نشده است.
